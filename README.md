# JDI 2.1 — настольное приложение

JDI — настольный планировщик для Windows: задачи, привычки, календарь и заметки. Этот репозиторий содержит приложение версии **2.1.0.0**, его исходный код, встроенные ресурсы интерфейса и зависимости, необходимые для сборки.

## Запуск

Скачайте `JDI-2.1.exe` из корня репозитория и запустите на Windows. Приложение использует Microsoft Edge WebView2 Runtime, который должен быть установлен в системе.

## Сборка из исходников

Нужны Windows и компилятор C# из .NET Framework 4.x (обычно `csc.exe` в `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319`). Из корня репозитория выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Сборка создаст `JDI-2.1.exe` в корне. Исходники интерфейса лежат в `src\assets` и включаются в настольное приложение как ресурсы WebView2; это не отдельный сайт и его не нужно запускать через браузер.

Пользовательские данные хранятся локально в `%LOCALAPPDATA%\JDI-Desktop`.
