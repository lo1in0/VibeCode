# JDI 2.2 — новый интерфейс

Windows x64, версия файла 2.2.0.0. Собрано 13 октября 2026 года.

## Запуск

Закройте ранее запущенную JDI и откройте `JDI-2.2.exe`. Для работы требуется Microsoft Edge WebView2 Runtime, как и в версии 2.1. HTML, CSS, JavaScript и библиотеки оболочки встроены в EXE; папка исходников для запуска не нужна.

Используется прежний профиль `%LOCALAPPDATA%\JDI-Desktop\profile`, адрес `https://jdi.local` и ключ данных `jdi.data.v1`. Данные установленной WebView2-версии 2.1 доступны новой версии без ручного переноса. Тестовые данные создавались в отдельном профиле внутри папки проверки, пользовательский профиль не изменялся. Старые EXE сохранены.

## Что изменилось

- Реализован новый дизайн из `design-preview`, обновлённый 13 октября: тёмное меню, бордовые акценты, светлые карточки, кнопка создания слева под заголовком, крупные формы.
- Главная: привычки и задачи на сегодня, ближайшие события, последняя заметка и итоги недели.
- Задачи: текущие и выполненные рядом, просроченные ниже; создание, изменение текста и даты, удаление, перенос на сегодня, история.
- Привычки: числовые и бинарные результаты, минимум и ориентир, расписание, редактирование с сохранением истории, удаление и завершение. Результат за день можно заменить или убрать; история доступна по месяцам с выбором даты.
- Календарь: дата и время события отдельно от уведомления; изменение и удаление событий, переход к дате из списка. Напоминание накануне в 08:00 можно отключить.
- Заметки: список рядом с полным текстом, поиск, избранное, редактирование. Закрытие изменённой формы запрашивает подтверждение потери изменений.
- Настройки: экспорт JSON, восстановление с проверкой структуры и подтверждением, отмена последнего восстановления, проверка уведомлений.

Уведомления требуют разрешения и запущенного приложения. Фактическое появление системного уведомления Windows в этой проверке не подтверждалось.

## Проверки

В собранном EXE с отдельным WebView2-профилем проверены создание/редактирование/выполнение задач, создание/редактирование событий, создание заметок, избранное, поиск, защита несохранённых изменений, привычки и сохранение истории, замена/очистка числового результата, бинарные отметки и отмена/подтверждение удаления. Проверено сохранение данных после перезагрузки интерфейса и повторного запуска EXE.

Сняты экраны пяти разделов при 1440×900, 1280×720 и 800×720, а также семь окон при 1440×1000. Горизонтального переполнения не обнаружено. Основные экраны и формы осмотрены визуально. Изображения используют тестовые записи.

Отдельный тест функций восстановления проверяет совместимость схемы, восстановление, резервирование прежних данных, отмену операции и отклонение некорректных дат/результатов. Выбор файла через системный диалог и системное окно сохранения экспорта вручную не проверялись.

## Исходники

`src/assets/app.js` — логика и интерфейс; `src/assets/design.css` — визуальная система; `src/assets/index.html` — оболочка; `src/Program.cs` — Windows/WebView2. `build.ps1` собирает готовый EXE через .NET Framework C# compiler. Сборка не требует Node.js.

Для сборки из исходников: `powershell -ExecutionPolicy Bypass -File .\build.ps1`.
Для дополнительной проверки резервных копий при установленном Node.js: `node backup-test.cjs`.
Для изолированной проверки EXE: `JDI-2.2.exe --smoke <полный_путь_к_отдельной_тестовой_папке>`. Не используйте пользовательский профиль как тестовую папку.
