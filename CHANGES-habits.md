# Изменения на базе JDI 2.1

- Редактирование сохраняет выбранный тип результата, расписание, дни недели и историю отметок.
- Проверка числовых целей: конечные положительные значения; недельная частота — целое число от 1 до 7.
- Результат «Да / нет» оценивается по порогу 1, включая ранее сохранённые привычки с другим числовым минимумом.
- Единый расчёт статистики для карточек и отчётов. Недельный период: воскресенье — суббота. Цель неполной недели ограничена числом доступных дней; дополнительные выполнения не компенсируют пропуски другой недели. Процент ограничен 100%, исходные отметки сохранены.
- Логика интерфейса выделена в `src/assets/app.js`; `smoke.js` содержит проверку настольного приложения. Оба файла встроены в EXE.

## Проверка

Финальная сборка: `D:\GPT\JDI\JDI-2.1-fixed.exe`.

Пройдены проверки создания привычки, бинарного результата, подстановки параметров, отмены редактирования, сохранения истории, отмены удаления и подтверждённого удаления. Проверены задачи, заметки, календарь, данные после перезагрузки интерфейса и полного закрытия/запуска EXE. Профиль проверки изолирован от пользовательских данных.

Математические проверки статистики: `node ../verification-data/statistics-test.cjs` из корня рабочей папки использовать `node verification-data/statistics-test.cjs`.

Предыдущее зависание воспроизводилось в песочнице; вне неё тесты WebView2 проходят. Проверка не является полным аудитом всех сценариев приложения.
